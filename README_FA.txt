# قفل کلمات — پروژهٔ اندروید

این بسته، **پروژهٔ منبع** بازی است؛ فایل APK آماده داخل آن نیست.
برای تبدیل پروژه به APK از GitHub Actions استفاده شده تا لازم نباشد روی گوشی ابزار کامپایل نصب کنید.

## فایل‌ها
- `main.py`: کد کامل بازی با رابط لمسی Kivy
- `buildozer.spec`: تنظیمات ساخت APK
- `.github/workflows/build-apk.yml`: ساخت APK در GitHub Actions

## ساخت APK با گوشی
1. وارد GitHub شوید و یک مخزن (Repository) جدید بسازید.
2. محتویات ZIP را از حالت فشرده خارج کنید و همهٔ فایل‌ها، از جمله پوشهٔ مخفی `.github`، را به مخزن اضافه کنید.
3. در مخزن، وارد زبانهٔ **Actions** شوید.
4. گردش‌کار **Build Android APK** را انتخاب کنید و روی **Run workflow** بزنید.
5. پس از پایان موفق، در بخش **Artifacts** مورد `ghofl-kalemat-debug-apk` را دانلود کنید.
6. ZIP آرتیفکت را باز کنید تا فایل `.apk` را پیدا کنید. هنگام نصب ممکن است اندروید اجازهٔ نصب از آن منبع را بخواهد؛ فقط اگر به منبع و فایل اعتماد دارید اجازه بدهید.

## نکته
این ساخت، APK آزمایشی (debug) تولید می‌کند. ساخت به سرویس GitHub و اینترنت نیاز دارد و ممکن است بسته به تغییرات ابزارهای Android build نیازمند اصلاح باشد. هیچ APK از پیش ساخته‌شده‌ای در این ZIP وجود ندارد.
